## 1. 最新版を iPhone で見る方法

### 方法A（推奨・外部に公開しない）：手元のPCで配信し、同じWi‑FiのiPhoneで開く
PC（Mac/Windows）に Node.js 20 以上と Git が入っていれば、次の手順で確認できる。

```sh
git clone https://github.com/twataru0129-dot/nazotoki.git
cd nazotoki
git checkout claude/chapter1-complete
npm ci
npm run build
npm run preview -- --host --port 4173
```

1. 表示された `Network: http://192.168.x.x:4173/nazotoki/` を、同じWi‑Fiにつないだ iPhone の Safari で開く。
2. 末尾の `/nazotoki/` まで入力する（無いと真っ黒になる）。
3. PCのファイアウォールが接続を止める場合は、Node.js の通信を許可する。
4. 終わったらPC側で `Ctrl + C` を押して止める。

- 外部には一切公開されない。保存データは iPhone の Safari に残る（確認後に「設定 > Safari > 詳細 > Webサイトデータ」で消せる）。
- PC版の Safari / Chrome で `http://localhost:4173/nazotoki/` を開いて、先に動作を見てもよい。

### 方法B（PC不要・非公開）：Claude の非公開ページ（Artifact）で試遊
- **URL：** https://claude.ai/artifact/T7wGpeJshyZMLjJ1MX9Z7C （2026-10-23 作成、第1版）
- **見られる人：** claude.ai にログインした持ち主だけ（共有設定をしない限り非公開）。iPhone の Safari、または Claude アプリから開ける。
- **中身：** 作業ブランチの最新版を、配信場所に依存しない形（相対パス）でビルドしたもの。ゲームの中身・素材は本番用と同じ。
- **本番との違い：**
  - claude.ai の画面の中に埋め込まれて表示される。
  - 画面上下の余白、全画面表示、ホーム画面への追加、保存データの残り方（端末のブラウザ内だが、本番URLとは別扱い）が本番と異なる可能性がある。
  - 本番URL（`/nazotoki/` 配下）での表示確認にはならない。
- 公開前の最終確認は、方法Aか本番URLで行うのが確実。

### 採らない方法
- **別リポジトリや作業ブランチから GitHub Pages に出す：** 公開状態になるため、承認前は行わない。

## 3. iPhone Safari で行う操作チェックリスト
各項目に ✅／❌ とメモを付けて返してもらえれば、修正に入る。

### 起動・表示
- [ ] URLを開くとタイトルが表示される（真っ黒・崩れなし）
- [ ] 縦向き：上下のバーと書斎の絵が重ならない。文字が読める大きさ
- [ ] 横向きに回す → 戻すで、絵とボタンがずれない。調べる場所の位置もずれない
- [ ] ノッチ／ホームバーにボタンが隠れない

### 音（iPhone 特有）
- [ ] 本体の消音スイッチ（サイレント）を **オフ** にした状態で確認
- [ ] 「はじめから」を押した直後にタイトルBGMが鳴る
- [ ] 手紙の後、書斎BGMと雨音に切り替わる。BGM が2曲重ならない
- [ ] 本の入れ替え・カード取得・時計・引き出しで効果音が鳴る。遅れ・欠けがない
- [ ] 2枚目のカード取得の少し後に「物音」が1回だけ鳴る
- [ ] 設定で BGM／環境音／効果音の音量・ミュートが効く
- [ ] ホームに戻る → ゲームに戻ると音が止まる → 再開する（二重にならない）
- [ ] 数分放置して、BGMのつなぎ目（約3分で一周）が途切れない

### 操作
- [ ] 左右の矢印・横スワイプで向きが変わる。縦スクロールでページ全体が動かない
- [ ] 本の並べ替え：タップ2回で入れ替え／ドラッグでも入れ替え
- [ ] 時計：±1分ボタンで合わせられる。分針のドラッグも効く
- [ ] 持ち物からカードを選んで扉の枠をタップ → はまる
- [ ] ダブルタップやピンチで画面が拡大されてしまわない
- [ ] ボタンが小さすぎて押し間違えることがない

### 進行・保存
- [ ] 途中で Safari を閉じる → 開き直すと「つづきから」で同じ場所・同じ状態から再開
- [ ] 謎の途中（本を並べかけ、扉にカードを置きかけ）で閉じても、続きから再開
- [ ] プライベートブラウズでは保存されない旨の案内どおりの動き（任意）

### エンディング
- [ ] 扉の演出 → 約28秒のエンディングが最後まで再生される。字幕が読める
- [ ] スキップが押せる。押してもクリア画面まで進む
- [ ] 書斎Bの違い：時計 00:14、赤い本、写真の人物
- [ ] 縦向きスマホでの上下の黒帯（エンディング映像の余白）が気にならないか
- [ ] クリア画面の「第1章を再調査」「エンディングをもう一度見る」「タイトルに戻る」が動く

### 背景（今回の修正分を含む）
- [ ] 南面：右側の机・椅子が消え、壁・腰板・床になっている。不自然でないか
- [ ] 南面：扉の縦横比・木目が気にならないか（作り直しを推奨中）
- [ ] 東面：壁の版画（屋敷の外観に差し替え）が世界観に合っているか
