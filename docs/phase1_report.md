# 第1段階 報告：基本画面・書斎の4方向探索

## 実装したもの

| 項目 | 内容 |
|---|---|
| 基本構成 | React 19 + TypeScript + Vite 7。`base: '/nazotoki/'`。ビルド成果物は `dist/app/`、ゲーム素材は `dist/assets/` |
| タイトル | はじめから／設定。「つづきから」はセーブ実装（第3段階）まで表示しない |
| 導入 | 雨の夜の導入文 → 城戸の手紙（確定文面、表裏）→ 背後で扉が施錠 → 書斎へ。スキップ可 |
| 4方向探索 | 北＝本棚＋机、東＝柱時計＋窓、南＝施錠扉、西＝絵画4枚（2×2）。初期は北 |
| 向きの変更 | 左右ボタン、横スワイプ（指を左へ払う＝右を向く）、キーボード←→。回転0.3秒 |
| 拡大表示 | 本棚・机（引き出し／小箱）・柱時計・扉・絵画・窓。戻る／ヒントへ。確定文言を表示 |
| 背景上の正確な表示 | 東：時計の文字盤と針をSVGで重ねて00:17（描き込みの針を隠す）。西：額の中に謎用SVGの絵4枚。南：扉の装置（縦長4枠＋ダイヤル）をSVGで重ねる |
| 探索補助 | 「調べる場所」で主要ホットスポットを1.5秒強調。ランプ・机上の紙は短い独白 |
| 基本UI | 持ち物（手紙を読める・裏返せる）、事件調査手帳（記録0/4・調査メモ0/6・手紙）、ヒント（5問×3段階の確定文面を1段階ずつ表示）、設定（BGM/環境音/効果音の音量とミュート、アニメーション軽減、タイトルへ戻る） |
| 音声（基本のみ） | 初回操作で有効化。タイトル＝title、探索＝study（排他・フェード）、雨音ループ（窓の拡大中は大きめ）、手紙・手帳で paper_turn。タブ非表示で停止 |
| レスポンシブ | 背景は4:3を contain で表示し、ホットスポットは背景比率（%）で配置。最小44px。横長画面では独白を右側に配置 |
| アクセシビリティ | 拡大画面・モーダル表示中は背後を `inert`。モーダルは常に1つ。Esc で閉じる |

## 背景（すべて「仮背景」と画面上に表示）

`scripts/build-assets.mjs` で元素材から再現可能な加工を行った（`docs/asset_build_report.md`）。

| 方角 | 加工内容 | 残る問題 |
|---|---|---|
| 北 | なし（元画像） | 中段に本4冊が描き込み済み（操作用SVGと二重になるため第4段階で空き棚化）。机上の写真がない（任意調査O1用） |
| 東 | 窓の外の西洋都市を、雨の夜の敷地（庭木・木立・遠い門灯）に差し替え。格子と1段目の月空は元画像 | 庭木は手描き調の合成で、写実の背景と質感差がある。壁の版画は西洋の大聖堂のまま |
| 南 | 開扉画像の扉板を射影変換して閉扉を作成（開扉と同じベース）。左壁（東壁にあたる）の本棚を壁で塗り替え、左右端を減光 | 右側に机とランプが残る（西壁側に机がある形）。扉の板は横に約1.5倍伸ばしている。**新規画像生成が必要になる可能性が最も高い** |
| 西 | 右端（北壁側）の窓とカーテンを壁と腰板に塗り替え | 右壁の上部は同じ帯の繰り返しで、近くで見ると単調 |

## 実行したテスト

- `npm run build`：成功（型検査含む）
- `npm test`（Vitest）：25件すべて成功
  - 4方向の配置（北本棚・机／東時計・窓／南扉／西絵画）、ホットスポットが背景範囲内、背景ファイルの存在、仮背景の明示
  - 画面遷移、4方向の回転、拡大中は回転しない、モーダル1つ、ヒント最大3段階
  - 音声20件（3/2/15）が無変換で配置（SHA-256一致）、ヒント15本、フォントに全文字が含まれる、設定の保存と破損時の既定値
- `npm run test:e2e`（Playwright／Chromium、375×667 と 1280×800 の2構成）：34件すべて成功
  - タイトル→手紙→書斎→4方向一周、スワイプ・キーボード、全ホットスポットの拡大と戻り
  - ホットスポットの位置を5種類の画面サイズ（375×667、667×375、390×844、1280×800、1024×1366）で画像に対して誤差1.5px未満で検証、縦横の切り替えでもずれない
  - 探索画面のボタンが44px以上、モーダルの開閉と非重複、拡大画面→ヒント→閉じると拡大画面に戻る、設定のリロード保持、`/nazotoki/` 配下のURL、コンソールエラー・404なし
