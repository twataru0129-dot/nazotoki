# 第3段階 報告：任意調査・イベント・ヒント／探索サポート・時間・セーブ・手帳

## 実装内容

### 任意調査6件（src/game/optional.ts、設計書§11）
| ID | 場所 | 出現条件 | 調べ方 |
|---|---|---|---|
| O1 写真の右端 | 机の拡大画面の古い写真（新規SVG） | 最初から | 写真の右端（光沢の違う部分）をタップ |
| O2 本棚の金具 | 本棚の隠し収納の奥 | 本棚の解決後 | 金具をタップ |
| O3 額縁の傷 | 絵画Cの裏 | 絵画の解決後 | 傷をタップ |
| O4 引き出しの刻印 | 右の引き出しの底「II」 | 右の引き出しを開けた後 | 刻印をタップ |
| O5 新しい蝶番 | 南の扉の右の戸枠（探索画面） | 最初から | 蝶番をタップ |
| O6 手紙の裏面 | 手紙の裏（持ち物・手帳・導入） | 最初から | 二本の跡をタップ |

- 発見時に短い独白＋「手帳に〇〇を書き留めた」。2回目以降は独白だけ（記録・演出は増えない）。
- 「調べる場所」の強調では光らせない。マウスを重ねても枠を出さない（伏線の位置を明かさない）。
- 手帳には発見済みの項目だけを発見順に表示し、未発見の名前は出さない。6件そろうと称号「観察者」。
- クリア条件ではない（0件でも解錠可、解錠後も集められる）。

### 一度きりのイベント
- **2枚目のカードを手にした時**：取得音の約1.6秒後に `mysterious_knock`、独白「……壁の向こうで、小さく『コトッ』と音がした。」
- **4枚目のカードを手にした時**：BGMと雨音を約3.5秒絞り、画面を一瞬暗く（音なしでも分かる）、独白で南の扉へ注意を向ける。
- 発生済みは `eventsSeen` に保存。再読み込みしても、カードを扉に置いて外しても再発しない。

### ヒントと探索サポート
- ヒント画面の上に「次に何を調べる？」（押したときだけ表示）。
  - 収納が開いたのに取っていないカード → その場所を案内
  - 鍵を持っていて木箱が未解錠 → 机へ案内
  - 4枚そろった → 南の扉へ案内／解錠後 → 先へ進める
  - それ以外 → 謎が残っている場所の一覧（答えと任意調査の場所は出さない）
- 謎のヒント15本は第2段階から保存済み。手帳にヒント使用数（n / 15）を表示。

### 時間の記録
- 探索中かつ画面が表示されている間だけ1秒ずつ数える（タイトル・オープニングの見返し・タブ非表示中は数えない）。
- 扉を解錠した瞬間のプレイ時間を `clearSeconds` に固定。以後は `afterClearSeconds`（再調査時間）を別に数える。
- 手帳の上部にプレイ時間・扉を開けた時間・ヒント数・調査メモ数。

### セーブの詳細（src/game/save.ts、saveVersion 2）
- 意味のある変化はすぐ保存。時間だけの変化は10秒おき。タブを隠す・ページを閉じる直前にも保存。
- 上書きの直前に、ひとつ前の正常な保存を予備（`study0017.ch1.save.prev`）に残す。
- 本体が壊れていた場合、タイトルで選択肢を出す：**ひとつ前の保存から再開**／**読み込めなかったデータをファイルに書き出す**／**最初から始める（壊れたデータは端末内に退避）**。黙って捨てない。
- v1（第2段階の形式）→ v2 へ自動移行（取得順はA→D、イベントは条件を満たしていれば発生済み、時間は0から）。タイトルで移行したことを知らせる。
- 検証項目を追加：取得順と所持カードの一致、イベントと所持枚数の一致、任意調査の出現条件、クリア時間と解錠の整合など。
- 保存に失敗したら探索画面の下に通知（遊び続けられる）。「はじめから」の確認文に消える範囲（第1章の進行のみ、設定と他章は残る）を明記。

### 手帳の記録画面
- 記録：時刻順／手に入れた順の切り替え。カードの表、発見場所、所持先（持ち物／扉の枠n）。
- 調査メモ：発見済みのみ、件数、称号。
- 手紙：表裏（裏の跡を調べられる）、「オープニングを見返す」（進行を変えず、終わると元の向きへ戻る）。

## テスト
- Vitest：90件すべて成功（第3段階で17件追加）
- Playwright（375×667／1280×800）：84件すべて成功（第3段階で18件追加）
  - 任意調査6件をUIで発見・出現条件・2回目で増えない・手帳6/6と称号・未発見名が出ない・強調で光らない
  - 物音／静寂が一度だけ（再読み込み後も）
  - 探索サポートの取り忘れ案内・4枚後の案内
  - プレイ時間（時計を進めて 01:05）、タブ非表示中は増えない、解錠でクリア時間固定・以後は別カウンター
  - 記録の並び替えと所持先、オープニングの見返し
  - 壊れた保存 → 書き出し（ダウンロード）→ 予備から再開、壊れたデータの退避
  - v1 保存の移行と再開
