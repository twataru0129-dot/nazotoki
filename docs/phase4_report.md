### 画質についての報告
南面の左右の家具の矛盾は、加工（塗り替え・減光）では解消しきれない。扉中心に切り抜いて拡大すると約1.6倍の引き伸ばしになり、木目や絨毯がぼやける。**対応案：** 閉扉の南面を「左に東壁（肘掛け椅子）、右に西壁（小卓と鉢植え）」で新規生成し、同じ画像から扉板を可動レイヤーにする（本プロジェクトの切り出し処理はそのまま使える）。

- 最初のユーザー操作で有効化、タブが隠れたら停止。音声が使えない環境でも全進行可能。

## 4. アニメーション（設計書§14の時間）
視点0.3秒／拡大0.25秒／カード獲得0.5秒（新規：浮かんで持ち物へ）／引き出し0.6秒・木箱0.8秒（新規）／本棚2.2秒・額1.8秒・時計2.2秒／**扉の解錠 約7秒**（装置 0〜1.5 → 反転 1.5〜3 → 図面がつながり光る 3〜4 → 解錠音 3.8 → 5.2秒で探索へ戻り扉が開く 1.8秒）。
- 成功演出は「その場で一度だけ」：画面を開き直しても、再読み込みしても繰り返さない。
- 動きを減らす設定：反転・飛び出し・クロスフェードを省き、扉の演出は約4秒の簡易版。

## 5. 扉の演出（src/components/DoorTransition.tsx、再利用部品）
暗闇に扉が浮かぶ（0〜1.8秒）→ 真鍮のノブがゆっくり回る（1.8〜3.2秒）→ 扉が奥へ重く開き通路の明かりが差す（3〜7秒）→ 通路へ踏み込み暗転（7〜9.6秒）。BGMを止め、きしみと足音だけを鳴らす。スキップ可、アプリが隠れたら一時停止。扉は書斎Aの閉扉と同じ画像から切り出し、装置は謎用SVG、ノブはSVGで新規作図（既存作品の素材は不使用）。終わると第5段階のエンディング（現在は仮画面＋reveal）へ。

## 6. テスト
- Vitest：96件すべて成功（第4段階で6件追加：書斎A/Bの描き分け、音量補正・ループ点）
- Playwright（375×667／1280×800）：104件すべて成功（第4段階で20件追加）
  1. 音声20ファイルを実際にデコードし、長さが管理表と±0.15秒以内
  2. BGM：タイトル→探索で切り替え（重ならない）、title・study・rain_loop を末尾2.5秒前へ進めると無音になる前に次の周回へつながる
  3. 効果音の順序と間隔（物音は取得の1.3秒以上後・一度だけ、解錠の反転は1.3秒以上・解錠音は3.5秒以上後、先へ進むはBGM停止→きしみ→4秒以上後に足音→reveal）
  4. ミュート・音量変更が系統ごとに反映
  - 洋館のきしみ：6分間で3〜9回、間隔40秒以上
  5. 4方向の背景、北の本が並び順どおり・赤い本なし・写真あり、東の時計00:17
  6・7. 正解演出は一度だけ、解錠演出の途中・扉の演出の途中で再読み込みしても進行が壊れない
  8. スマホ縦で戻る・ヒント・先へ進む・スキップが画面内かつ44px以上
  9. AudioContext が使えない環境で最後まで進行
  10. 第3段階までの84件に回帰なし（新しい流れに合わせてテスト2件の手順を更新）
- **未確認：** iPhone 実機（iOS Safari の音声有効化・ループの聴感・音量バランス・タブ切り替え時の停止）、人の耳による聴感確認。
