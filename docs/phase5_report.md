## エンディングの流れ
1. 扉の正解（00:14 ＋ ◇○□△）→ カード反転・見取り図 → 解錠演出（約7秒）→ 探索画面で扉が開く
2. 「先へ進む」を押すまでは書斎を自由に再調査できる
3. **扉の演出**（第4段階の DoorTransition を再利用、約9.6秒）：暗転 → 暗闇に扉 → 真鍮のノブ → 扉が奥へ開く → 通路へ。BGM停止、door_open が主役
4. **ラストシーン 28秒**（src/components/EndingSequence.tsx、台本は src/game/ending.ts）

|---|---|---|---|
| 0〜5秒 | 暗い通路を一人称で前進 | 0.7〜4.6「……まだ、屋敷の中なのか？」 | reveal（控えめ）・0.3秒 footsteps_hallway |

## 操作・アクセシビリティ
自動進行／右上にスキップ（扉の演出中・ラストシーン中どちらでもクリア処理まで進む）／独白はすべて字幕／動きを減らす設定ではズームや扉の回転を省きクロスフェードだけ／アプリが隠れたら時刻ごと停止（「一時停止中」）／音が出なくても字幕と映像で理解できる。

## クリア画面
第1章クリア、クリア時間（扉を解錠した瞬間で確定。演出時間は含まない）、解決した謎 5/5、ヒント開示数 n/15、隠し調査メモ n/6（6件で称号）。
ボタン：**第1章を再調査**（南を向いて探索へ。謎は解けたまま）／**エンディングをもう一度見る**（進行は変えない）／**タイトルに戻る**／**第2章（準備中）**（押せない）。
再調査中は探索画面の上部に「クリア画面」ボタン。手帳の記録に「もう一つの書斎」を追加。

## セーブ（saveVersion 3）
| 状態 | 保存値 |
|---|---|
| 最後の扉の解錠済み | `door.unlocked` |
| エンディング再生中 | `ending: 'playing'`（中断したら次回は扉の演出から） |
| エンディング完了済み | `ending: 'done'` |
| 第1章クリア済み | `chapterCompleted`・`clearedAt`（初回の日時、以後変わらない） |
| クリア後の再調査中 | `revisiting` |
v2 → v3 は自動移行（エンディング未再生として扱う）。矛盾（未解錠で再生中、未完了なのにクリア等）は読み込まない。
