# 試遊後の修正（1）：机のタップ領域・引き出しの横並び・ヒント機能の廃止

## 1. 机のタップ領域
- **原因：**
  - 北面の「机の引き出し」は、机の前面全体を1つの大きなタップ領域にしていた。
  - スマホでは、小さな領域を最小44pxへ中心から広げるため、引き出しの領域が天板の手前（写真・紙の下側）まで広がっていた。
  - 机上の写真・小箱をタップしても、引き出しのある机の画面が開いていた。
- **変更：**
  - 天板の物と前面の引き出しを、別々のタップ対象にした。
    | 対象 | 反応 |
    |---|---|
    | 写真 | 写真の拡大画面（右端の任意調査O1あり） |
    | 小箱 | 小箱の画面（鍵を使う・カードC） |
    | 紙・ランプ | 従来どおりの独白 |
    | 左・中央・右の引き出し | 引き出しの画面 |
  - タップ領域の計算を `tapRects()`（src/game/geometry.ts）に置き換えた。
    - 小さな物は従来どおり最小44pxまで広げる。
    - 隣と重なる部分は、元の矩形どうしの隙間の中央で切る。
    - 実際のステージ幅を ResizeObserver で測り直すため、画面の回転・サイズ変更・ブラウザの拡大率の変更にも追従する。
  - 机の上の小物のように近接した物は、小型スマホで30〜40px程度になる（重ならないことを優先）。
  - 南面の扉と蝶番（O5）の領域が16px重なっていたため、扉の領域を蝶番の手前までにした。
- **確認（テスト）：**
  - 同じ方角の領域どうしが重ならないこと（単体）。
  - 画面幅240〜2000pxの11通りで、広げた領域どうしが重ならず、元の矩形を含み、背景からはみ出さないこと（単体）。
  - 5種類の画面サイズで、写真の中央・下端、小箱、紙、ランプ、3つの引き出し、関係のない3か所を指／マウスで押し、それぞれの反応を確かめる。画面サイズを変えた後にも同じ確認を行う（E2E）。

## 2. 机の3つの引き出し
- 左・中央・右を横3列に並べた。スマホ縦画面でも3列のまま。
- 見た目：天板の木口、木目、面取り、真鍮の札差しに入れた札、真鍮の吊り手。
- 札の文字は15px以上。狭い画面では、文節（「鍵は／中央には／ない」）の途中で改行しない。
- 札の文言、正解（右）、鍵、「II」の刻印（O4）、小箱の解錠は変更なし。

## 3. ヒント機能の廃止
- 削除したもの：
  - 下部メニューの「ヒント」
  - 拡大画面の「ヒント」ボタン
  - 15本の段階式ヒントの本文
  - 「次に何を調べる？」（探索の手がかり）
  - 手帳とクリア画面のヒント数
  - 進行データの `hintLevels`
- 下部メニューは「持ち物・手帳・設定」の3列。拡大画面の見出しは中央寄せ。
- **保存データ：** 版を4にした。
  - v3（ヒントあり）以前のデータは、`hintLevels` を捨てて読み込む。
  - `hintLevels` の中身が壊れていても、読み込みを止めない。
  - v1・v2 からも続けて移行できる。
- 残したもの：
  - 謎に必要な刻印・札・記録カード・時計の説明・事件調査手帳
  - 操作の説明（「開けたい引き出しをタップする」など）
  - 「調べる場所」ボタン（調べられる場所の枠を一時的に光らせる。謎の答えは示さない）
